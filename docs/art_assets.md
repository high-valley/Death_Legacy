# 絵の素材リスト（デスレガ）

`art/` フォルダに、下の**決まった名前**で画像を置くと、ゲームに自動で入ります（ビルド時にフォルダを調べます）。
置いていない絵は、図形の仮表示（等級色の光・紋章・CSS の情景）のままです。1枚ずつ足していけます。

- 形式: `.webp`（おすすめ）/ `.jpg` / `.png`（ロゴは透過 PNG）
- 1枚あたり **300KB 以内**が目安（スマホで重くならないように）
- 画風: オーナーの画面イメージ（青い霊光が強いアニメ調のダークファンタジー）。ChatGPT 向けのプロンプトは `docs/art_prompts.md`
- サイズはぴったりでなくてよい（もらった画像をこちらで切り抜き・縮小・webp 変換する）

## 動き（アニメーション）
- 1枚絵のままでも、コードで動かす（歩くと弾む・左右に揺れる・足元に土ぼこり／剣を振る時はためて踏み込み、残像と三日月の斬撃。`src/view/heroAnim.ts`）。
- コマ絵があれば自動で使う（無いコマは1枚絵のまま）: `sprite_hero_<武器>_walk_1`〜`_N`（歩き、4コマ目安）、`sprite_hero_<武器>_attack_1`〜`_N`（振り、3コマ目安）。横並びの1枚（スプライトシート）でもらえば、こちらで切り分ける。

## 肖像の名前の付け方
- `<武器>` は `sword`（剣）/ `bow`（弓）/ `fire`（炎の魔導書）/ `ice`（氷の魔導書）/ `thunder`（雷の魔導書）/ `spear`（槍）/ `axe`（斧）
- 例: `portrait_sword_1.webp`, `portrait_sword_2.webp`, `portrait_bow_1.webp` …
- 武器ごとに **2〜4枚**あると、同じ顔ばかりにならない。亡霊ごとに決まった1枚が選ばれる（同じ亡霊はいつも同じ顔）
- 武器を分けない場合は `portrait_1.webp`, `portrait_2.webp` … でもよい（武器別が無い時に使う）
- 等級（残響〜伝説の英霊）の色の枠と光は画面側で付けるので、絵に色を付ける必要はない

## 入れ方
1. 画像をこのチャットに添付してもらえれば、名前を付けて組み込みます（いちばん簡単）
2. 自分で入れる場合は、GitHub のリポジトリで `art` フォルダを開き「Add file → Upload files」でドラッグ＆ドロップ → 「Commit changes」。数分で公開版に反映されます
